 QSO Practice Project

 About This Project

QSO Practice Project is a practice website created to help me learn HTML, organize project files, and use Git for version control.

 Project Files

* `index.html` — The home page of the website.
* `about.html` — Provides information about the author.
* `projects.html` — Displays information about my projects.
* `contact.html` — Provides contact information.
* `images/` — Stores images used on the website.
* `css/` — Stores CSS stylesheets.
* `js/` — Stores JavaScript files.

 Technologies Used

* HTML5
* Git
* GitHub

 Author

Amie Jallow

 Purpose

The purpose of this project is to practice creating a website, organizing files into folders, and tracking changes using Git and GitHub.
